# gpt-2-to-gpt-oss-one-change-at-a-time
Six years separate GPT-2 from OpenAI's open-weight gpt-oss, and almost every part of the transformer block changed in between. This project rebuilds that history at a scale you can train on a CPU. You start with a character-level GPT-2 trained on children's stories: learned absolute positions, LayerNorm, a GELU feed-forward layer, full multi-head…
